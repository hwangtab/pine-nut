# 풍천리 사이트 리디자인 — "숲의 편지" 설계서

- 작성일: 2026-08-19
- 상태: 사용자 승인 완료 (방향 B "숲의 편지" 확정)
- 범위: 공개 페이지 전체의 비주얼 리디자인. 콘텐츠 문안·IA·라우팅·백엔드는 불변

## 1. 배경과 목표

현재 디자인은 iOS 리퀴드 글래스(도시적) + 흙/숲 컬러(자연) + 채도 높은 단색 카드(프레젠테이션풍) 세 가지 언어가 충돌하고, 히어로의 유리 패널이 핵심 자산인 사진을 가린다. 섹션마다 배경색이 바뀌는 패치워크(크림→흰→베이지→네이비→검정→초록)가 산만함을 더하고, 강력한 콘텐츠(주민 증언, 시위 사진, 7년/705회 숫자)가 묻힌다.

목표: 사이트 전체를 **풍천리가 보내온 한 통의 편지**로 재구성해, 지키려는 것(숲·마을·삶)을 아름답게 보여줌으로써 서명 전환을 높인다. 서정이 기본 정서, 긴장은 사실 진술과 숫자가 담당한다.

## 2. 핵심 컨셉 — 서명은 "숲에 보내는 답장"

- 히어로 = 편지의 첫 문장, 본문 섹션 = 편지의 단락, 서명 = 방문자의 **답장**
- 서명 폼 = 편지지, 참여 카운트 = 소인(消印) 스탬프, 공유 = 편지 전달
- 기존 GA4 퍼널(signatureStart → signatureComplete → shareClick)을 서사로 그대로 감싼다. 퍼널 이벤트 정의는 변경하지 않는다

## 3. 디자인 토큰

### 3.1 팔레트 — "한지와 숲"

| 역할 | 값(기준) | 용도 |
|---|---|---|
| 배경 `--color-bg` | 한지 크림 `#FAF7EF` | 전 페이지 단일 배경. 섹션별 배경색 패치워크 폐기 |
| 보조 배경 | 옅은 이끼 세이지 (크림에서 한 단계) | 섹션 구분이 꼭 필요할 때만 |
| 잉크 `--color-text` | 침엽수 차콜 `#22301F` 계열 | 본문·제목. 순검정 금지 |
| 브랜드 | 잣나무 그린 (기존 `--color-forest` 계승) | 아이콘·포인트 그래픽 |
| 액션 | 감빛 (기존 `--color-warm` 계승) | **서명 CTA 단독 사용** — color diet 규율 유지 |
| 깊은 배경 | 깊은 숲 그린 | 기존 네이비(`--color-sky`) 밴드·검정 밴드를 전부 대체 |

- `--color-sky`(네이비)는 대형 배경에서 퇴출하고 기능적 용도(뱃지 등)로만 축소
- admin 전용 토큰(`--color-admin-*`)은 건드리지 않는다

### 3.2 재질 — 유리에서 종이로

- **리퀴드 글래스 시스템 전면 제거**: `.glass`, `.glass-strong`, `.glass-subtle`, `.glass-dark`, `.glass-chip`, `.glass-btn--glass` 및 관련 토큰 삭제
- `.frost` 계열(읽는 유리)은 **종이 카드**로 대체: 한지색 표면 + 옅은 CSS 노이즈 질감 + 부드러운 그림자. 폼 필드(`.frost-field`)는 종이 위 필기 칸 스타일로 재작성
- `frost-sheet`(모바일 메뉴 시트)는 불투명 한지색 시트로 대체
- radius·shadow 토큰은 유지하되 종이 질감에 맞게 값만 조정

### 3.3 타이포그래피

- **디스플레이**: 마루 부리(네이버, SIL OFL) 셀프호스팅 — woff2 서브셋, 폴백 나눔명조. 히어로·섹션 제목 담당
- **본문**: Pretendard 유지 (기존 셀프호스팅 그대로)
- **손글씨**: 나눔손글씨 계열 1종 — 증언의 서명·사진 캡션에만. 본문·제목 사용 금지
- 히어로 디스플레이는 현재보다 한 단계 크게, 섹션 제목은 획일적 센터 정렬을 버리고 좌측 정렬 기본
- keep-all, text-wrap balance/pretty 등 기존 한글 조판 규칙 전부 유지

### 3.4 그래픽 모티프 — 전부 코드(SVG/CSS)로 제작

| 모티프 | 용도 |
|---|---|
| 등고선 패턴 | 섹션 배경 장식 (옅게) |
| 산 능선 실루엣 웨이브 | 섹션 구분선, 푸터 상단 경계 |
| 잣나무·잣송이 실루엣 | 불릿, 아이콘, 로고 보조 |
| 우표 테두리 + 원형 소인 스탬프 | 서명 CTA 전용 |
| 오솔길 점선 | 타임라인 연결선 |

- 일러스트레이터 발주 없음. **AI 생성 일러스트 금지** — 진정성 훼손 리스크
- 사진이 주인공, 모티프는 여백의 장식. 사진은 앨범 프레임(흰 테두리, 미세 회전, 둥근 모서리) 처리

## 4. 홈 페이지 재구성 (편지의 순서)

1. **히어로**: 안개 숲 풀블리드 사진. 유리 패널 제거, 사진 위 직접 마루 부리 헤드라인 + 하단 크림 그라디언트로 본문 연결. CTA는 감빛 버튼 1개
2. **편지의 도입**: "풍천리를 아시나요" — 큰 사진 + 서정적 소개, 등고선 배경
3. **잃게 될 것들**: 단색 아이콘 카드 4장 폐기 → 사진 + 짧은 사실 진술. 잉크 대비를 홈에서 가장 강하게 (서정 속의 긴장 담당)
4. **7년의 발자취**: 타임라인 하이라이트 3–4개를 오솔길 점선으로 연결, /timeline 유도
5. **주민의 목소리**: 네이비 밴드 폐기 → 편지지 카드 위 증언 + 손글씨 서명 포인트
6. **답장을 보내주세요**: 편지지 폼 + 우표·소인 그래픽 + 실시간 카운트. 인라인 서명 폼 로직(`HomeInlineSignatureForm`, `useHomeSignatureActivity`)은 그대로 재사용
7. **숫자 밴드**: 흩어진 통계를 깊은 숲 그린 밴드 하나로 통합
8. **푸터**: 능선 실루엣 경계 + 깊은 숲 그린

## 5. 공통 컴포넌트

- **Navigation**: 유리 캡슐 → 한지색 종이 바(스크롤 시 옅은 그림자). 메뉴 구조·항목 불변
- **SubHero**: 유리 패널 제거 → 사진 + 마루 부리 타이포 + 능선 하단 경계. 전 서브페이지 일괄 수혜
- **Footer**: 능선 실루엣 상단 경계 + 깊은 숲 그린 배경

## 6. 서브페이지 적용 순서와 방향

| 순서 | 페이지 | 방향 |
|---|---|---|
| 1 | /story | 수필(에세이) 레이아웃 — 넉넉한 행간, 큰 사진, 인용 강조 |
| 2 | /timeline | 발자취 세로 오솔길(점선) + 연도 챕터 |
| 3 | /petition | 답장 컨셉 전면화 — 편지지 폼, 우표·소인, 최근 서명 = 도착한 답장들 |
| 4 | /gallery | 사진 앨범 프레임 그리드 |
| 5 | /press, /news | 신문 스크랩 모티프 절제 사용 |
| 6 | /concert, /donate, /board, /share, 인증(login/signup/mypage) | 토큰·컴포넌트 교체 위주 |
| 7 | /en 전체 | 한글판 확정 후 동일 적용 |

## 7. 보존 목록 (회귀 금지)

- 접근성: `prefers-reduced-motion` / `prefers-reduced-transparency` 폴백, `:focus-visible` 스타일, skip 링크, keep-all
- 성능: LCP 요소에 CSS 애니메이션(js 하이드레이션 비의존) 전략, below-fold 전용 reveal, 폰트 1년 불변 캐시 헤더
- 기능: 서명 폼 검증·중복 방지·rate limit 흐름, GA4 퍼널 이벤트, SEO 메타데이터·sitemap·OG 이미지 구성
- 콘텐츠: 문안·사진·데이터 변경 없음 (섹션 재배치는 허용, 삭제는 홈의 중복 숫자 밴드만)

## 8. 비범위 (Non-goals)

- /admin 영역 전체 (별도 admin 토큰 체계 유지)
- IA·라우팅·메뉴 구조 변경
- API·DB·Supabase 스키마 변경
- 콘텐츠 문안 재작성 (마이크로카피 수준의 은유 표현 조정만 허용: 예. CTA 레이블)
- 다크 모드 도입

## 9. 구현 단계

1. **토큰·타이포·모티프 기반**: globals.css 재작성(글래스 제거, 종이 재질), 마루 부리·나눔손글씨 셀프호스팅, SVG 모티프 컴포넌트 제작
2. **홈 재구성**: 8개 섹션 순서·스타일 교체
3. **공통 컴포넌트**: Navigation, SubHero, Footer
4. **서브페이지 순차 적용**: 6장의 표 순서대로

각 단계 완료 시 chrome-devtools로 데스크톱(1440)·모바일(390) 스크린샷 시각 검증 + `npm run lint` + `npm run build` 통과 확인. 커밋은 단계 단위, 한국어 컨벤션("변경 요약 + 영향 범위").

## 10. 리스크와 완화

| 리스크 | 완화 |
|---|---|
| 서정 과잉으로 투쟁의 긴박함 약화 | "잃게 될 것들" 섹션과 숫자 밴드는 잉크 고대비 + 사실 진술로 무게 유지. CTA는 감빛 단독으로 명확히 |
| 손글씨·모티프 과용으로 유치해짐 | 손글씨는 서명·캡션 한정, 모티프는 여백 장식 한정을 규칙으로 명문화 (본 문서 3.3, 3.4) |
| 글래스 제거 중 스타일 회귀 | 클래스 삭제가 아니라 대체 클래스로 치환 후 잔여 참조 grep 검증 |
| 폰트 추가로 성능 저하 | woff2 서브셋 + 기존 불변 캐시 헤더 + `font-display: swap`, 디스플레이 폰트는 위계상 필요한 웨이트 1–2개만 |
