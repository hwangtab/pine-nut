# 풍천리 잣나무 마을 잔치 리플렛 — 설계

**작성일**: 2026-09-02
**용도**: 9월 5일 잔치 당일 현장에서 나눠주는 프로그램북. A4 양면 3단 감싸접기.

---

## 1. 무엇을 만드나

잔치에 온 사람이 받아서 순서를 확인하고, 끝나면 집에 가져가는 인쇄물이다.
두 가지 일을 동시에 해야 한다.

1. **오늘 무슨 일이 벌어지는지 알려준다** — 몇 시에 누가 무대에 오르는가.
2. **왜 이 잔치인지 남긴다** — 잔치가 끝나고 집에서 다시 펼쳤을 때, 풍천리가
   무엇을 겪고 있는지가 손에 남아야 한다.

두 번째가 없으면 그냥 순서표다. 첫 번째가 약하면 현장에서 쓸모가 없다.

## 2. 판형과 접지

| 항목 | 값 |
|---|---|
| 재단 후 크기 | 297 × 210㎜ (A4 가로) |
| 재단 여백 | 사방 3㎜ (작업 크기 303 × 216㎜) |
| 접지 | 3단 감싸접기(롤폴드) |
| 접지선 | 왼쪽에서 100㎜, 199.5㎜ |
| 색 | CMYK |
| 종이 | 스노우지 150g 내외 (인쇄소 권장에 따름) |

면 폭은 같지 않다. 안으로 말려 들어가는 면을 2.5㎜ 좁게 잡는다 — 같은 폭이면
접었을 때 접힌 면이 튀어나와 걸린다.

```
겉면(Side 1)   좌 → 우
┌────────────┬────────────┬────────────┐
│   플랩     │   뒤표지   │    표지    │
│  97.5㎜    │   99.5㎜   │   100㎜    │
└────────────┴────────────┴────────────┘

안면(Side 2)   좌 → 우  (겉면을 세로축으로 뒤집은 것)
┌────────────┬────────────┬────────────┐
│  표지 뒷면 │ 뒤표지 뒷면│ 플랩 뒷면  │
│   100㎜    │   99.5㎜   │  97.5㎜    │
└────────────┴────────────┴────────────┘
        └─── 오늘의 순서 — 297㎜ 한 판 ───┘
```

안면은 세 칸을 나누지 않고 297㎜ 한 판으로 쓴다. 다만 접지선(100㎜·199.5㎜)에
글자나 얼굴이 걸리지 않게 배치한다.

## 3. 색과 활자

포스터의 형광 연두는 RGB 색이라 CMYK로 변환하면 눈에 띄게 탁해진다. 별색을
추가하면 살릴 수 있지만 비용이 붙는다. **리플렛은 처음부터 짙은 초록 기조로
잡아 CMYK에서 안전하게 간다.**

| 쓰임 | 색 |
|---|---|
| 바탕(표지·뒤표지) | `#2D5016` (`--color-forest`) |
| 바탕(안면) | 종이 흰색 |
| 강조 | `#C75000` (`--color-warm`) — 시각 표기, 서명 유도 |
| 본문 활자 | 짙은 초록 바탕 위 흰색 / 흰 바탕 위 `#1a1a1a` |

이 결정의 결과: **표지에 포스터 JPG를 그대로 얹지 않는다.** 포스터가 통째로
형광 연두 바탕이기 때문이다. 제목·날짜·장소·출연진 아홉 이름은 포스터와 같은
구성으로 다시 조판하되 색을 뒤집는다.

활자는 사이트와 같은 것을 쓴다 — 본문 Pretendard, 인용문 나눔명조/마루부리.
`website/public/fonts/` 에 이미 있다.

### 플랩 (겉·왼쪽, 97.5㎜) — 표지를 젖히면 처음 보이는 면

**왜 이 잔치인가.** 사실은 여기서만 말한다.

- 2019년 3월 첫 집회 이후 705회. 예순에서 여든의 주민들이 지켰고, 그중 일곱 분이
  지금 재판을 받고 있다.
- 산림청 100대 명품숲 1,800㏊. 잣나무 약 11만 그루가 벌채될 예정이다.
- 51가구가 수몰된다. 풍천리 주민의 약 70%가 잣으로 먹고산다.
- 작년 「잣나무골 여름잔치」에서 주민 허순이 씨가 한 말:
  > "사람답게 산 것 같다. 몇 년 만에 웃어봤는지 모르겠다."

이 면의 주인공은 마지막 인용문이다. 통계는 인용문을 떠받치는 자리에 둔다.

## 5. 만드는 방법

`docs/promo/leaflet/` 에 정적 파일 한 벌을 두고 Chrome headless 로 PDF 를 뽑는다.
새 의존성도, 빌드 훅도 만들지 않는다.

```
docs/promo/leaflet/
├── leaflet.html      # 6면 전체 (Side 1 / Side 2 두 페이지)
├── leaflet.css       # @page size: 297mm 210mm; margin: 0
├── fonts.css         # website/src/app/fonts/pretendard.css 의 절대경로를 상대경로로
└── qr/               # npx qrcode 로 뽑은 SVG 3개
```

- 폰트: `pretendard.css` 는 `/fonts/...` 절대경로라 `file://` 에서 깨진다.
  경로만 상대경로로 바꾼 사본을 `fonts.css` 로 둔다.
- 사진: `website/public/images/concert/artists/*.jpg` 를 상대경로로 참조한다.
- QR: `npx qrcode` 로 SVG 3개를 뽑아 `qr/` 에 둔다. 의존성은 추가하지 않는다.
- 출력:
  ```bash
  '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
    --headless --disable-gpu --no-pdf-header-footer \
    --print-to-pdf=docs/promo/leaflet/village-feast-leaflet.pdf \
    docs/promo/leaflet/leaflet.html
  ```

## 6. 검증

1. **접어본다** — 뽑은 PDF 를 A4 양면 인쇄해 실제로 접는다. 접지선에 얼굴이나
   글자가 걸리지 않는지, 플랩이 걸리지 않고 들어가는지 본다. 이 확인 없이
   인쇄소에 넘기지 않는다.
2. **폰트 임베딩** — `pdffonts` 로 Pretendard 가 PDF 에 박혔는지 본다. 안 박히면
   인쇄소에서 다른 활자로 대체된다.
3. **양면 맞춤** — Side 1 과 Side 2 의 접지선이 100㎜·199.5㎜ 에서 만나는지.
   뒤집었을 때 어긋나면 안면 내용이 접지선에 걸린다.
4. **사실 대조** — 타임테이블·전화번호·URL 을 `concert.ts` 와 보도자료에 대조한다.

## 7. 정하지 않은 것

- **후원 계좌번호** — 알려주시면 뒤표지에 넣는다. 지금은 QR 로만 간다.
- **인쇄 부수와 종이** — 인쇄소 견적에 따라 정한다. 설계에는 영향이 없다.
